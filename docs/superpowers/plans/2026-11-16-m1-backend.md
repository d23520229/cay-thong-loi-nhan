# M1 — Backend: kế hoạch thực hiện

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Server Fastify chạy được đủ API P0 của chủ cây và người viết (tạo phòng, xác thực, lưu phòng, treo/sửa/gỡ lời nhắn, chủ cây đọc/chặn/báo cáo), mọi API có test trên PGlite.

**Architecture:** `buildApp({ db, now, env, google })` dựng Fastify; route chia theo file trong `apps/server/src/routes/`; mọi băm/khoá/giới hạn nằm ở `security.ts`; mọi kiểm tra giai đoạn qua `phase.ts`. CSDL: SQL viết tay là gốc, Drizzle `schema.ts` chỉ để có kiểu. Test dùng `app.inject()` trên PGlite với đồng hồ giả.

**Tech Stack:** Node 22, TypeScript, Fastify 5, `@fastify/cookie`, `@fastify/helmet`, Drizzle ORM (`drizzle-orm/pglite` khi test, `drizzle-orm/postgres-js` khi chạy), Zod 3, Vitest 3, `google-auth-library`. Không thêm thư viện ngoài `package.json` hiện có (trừ `zod` vào `packages/shared`).

**Spec:** `docs/dac-ta-v3.md` — mục 5, 6.4, 7.3–7.6, 7.9, 8.1–8.5, 8.8, 9.1–9.6, 9.11, 10. Đọc cùng `docs/tien-do.md`.

## Global Constraints

- Chữ hiển thị cho người dùng (trường `message` trong lỗi) bằng **tiếng Việt**. Mã lỗi (`code`) tiếng Anh snake_case.
- Dạng lỗi thống nhất: `{ "error": { "code": string, "message": string } }`.
- Mã HTTP theo 8 (đặc tả): 400 sai dữ liệu · 401 chưa xác thực · 403 bị chặn/không quyền · 404 · 409 xung đột · 410 dịch vụ kết thúc · 423 chưa đến giờ mở · 429 · 503 tạm dừng.
- Mọi so sánh giai đoạn qua `currentPhase(now())` trong `apps/server/src/phase.ts`. Không so sánh ngày ở chỗ khác. Mốc mặc định: `UNLOCK_AT=2026-12-24T00:00:00+07:00`, `WRITE_CLOSES_AT=2026-12-26T00:00:00+07:00`, `SERVICE_ENDS_AT=2027-01-01T00:00:00+07:00`, `PURGE_AT=2027-01-07T00:00:00+07:00`.
- Giai đoạn `ENDED` → mọi `/api/*` (trừ `/api/config`) trả **410** `service_ended`. Ghi khi `NOTICE` → **403** `write_closed` ("Cây đã ngừng nhận thay đổi từ 26/12.").
- Không lưu khoá thô, IP thô, email người dùng. Khoá/phiên/token: HMAC-SHA256 với `PEPPER`. PIN: scrypt + muối riêng.
- Không trả `messages.content` ở bất kỳ API nào ngoài `GET /api/messages/:mid/mine` (đúng token) và `POST .../open` (chủ cây, `canRead`).
- Giới hạn lấy từ `catalog.limits`: `maxItems 25`, `scaleMin 0.5`, `scaleMax 1.6`, `messageMax 300`, `nameMax 30`, `titleMax 40`, `perDeviceMessages 3`, `editMinutes 15`. Phòng 720×1080, `floorY 770`.
- Giới hạn tần suất (đặc tả 10): tạo phòng **5/giờ/IP**; lời nhắn **20/giờ/IP**; lưu phòng **120/giờ/phòng**; PIN sai **5 lần/phòng → khoá 15 phút**, **20 lần sai/IP/giờ**.
- Body tối đa **64 KB**. API ghi chỉ nhận `Content-Type: application/json` (415 nếu khác).
- Cookie chủ cây: tên `ctln_owner_{treeId}`, HttpOnly, SameSite=Lax, Path `/`, Secure khi `NODE_ENV=production`, hết hạn `PURGE_AT`.
- Không sửa `0000_init.sql`; cần đổi CSDL thì thêm `0001_*.sql` và cập nhật `docs/schema.postgres.sql`. Không thêm bảng vào schema `public` (giữ 16 bảng).
- Mỗi task kết thúc bằng `pnpm test` và `pnpm typecheck` sạch rồi commit; message commit kết thúc bằng `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Hai người treo cùng một điểm cùng lúc** → đúng một người được 201, người kia 409 `slot_taken` (test ở Task 8).
2. **Lời nhắn có emoji/tiếng Việt có dấu**: giới hạn 300 tính theo **ký tự thấy được (code point)** như `char_length` của PostgreSQL, không theo UTF-16; chuỗi chỉ có khoảng trắng bị từ chối (test ở Task 1).
3. **Biên giờ Việt Nam**: `23:59:59 23/12 (+07)` mở lời nhắn → 423; `00:00:00 24/12 (+07)` → 200 (test ở Task 9).
4. **Cookie chủ cây phòng A dùng cho phòng B**, phiên đã thu hồi hoặc hết hạn → 401 (test ở Task 7).
5. **Body sai JSON, quá 64 KB, thiếu `X-Device-Id`** → 400/413/400 với `message` tiếng Việt, không lộ stack (test ở Task 4).
