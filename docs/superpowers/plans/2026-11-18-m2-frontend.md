# M2 — Frontend phòng tự do: kế hoạch thực hiện

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web app React cho chủ cây tạo và trang trí căn phòng (điện thoại + máy tính), tự lưu lên server M1, mở lại cây bằng mã cây + PIN.

**Architecture:** "Bộ não" phòng là module thuần `apps/web/src/room/model.ts` (không React, test đầy đủ). Component chỉ hiển thị và gọi hàm của model qua một store Zustand. Tự lưu là module riêng `room/autosave.ts` điều khiển bằng hàm tiêm vào (api, storage, đồng hồ) để test bằng đồng hồ giả. Phòng 720×1080 dựng bằng thẻ HTML/ảnh, co theo vùng hiển thị.

**Tech Stack:** React 19, Vite 6, TypeScript, react-router 7, zustand 5, @tanstack/react-query 5, Vitest 3 + React Testing Library + jsdom. Đồ hoạ từ `@ctln/art`, danh mục và schema từ `@ctln/shared`.

**Spec:** `docs/dac-ta-v3.md` — **mục 6.5 (chính)**, 3.1 (R1–R10), 8.2–8.3, 9.1–9.3, 9.11, 11. Đọc cùng `docs/tien-do.md` và bản thiết kế canvas `tools/design-canvas/build-board-free.mjs` (logic gốc) + mẫu đã duyệt `tools/design-canvas/build-mock-m2.mjs`.

## Global Constraints

- Mọi chữ hiển thị bằng **tiếng Việt**, đúng câu chữ trong đặc tả 6.5 khi đặc tả đã ghi.
- Không thêm thư viện chạy (runtime). Chỉ thêm devDependencies: `@testing-library/user-event`, `@testing-library/jest-dom`.
- Không sửa `packages/shared/src/catalog.json` (sinh tự động). Ảnh ở `/assets/{đường dẫn trong catalog}` (thư mục `apps/web/public/assets`).

- Mọi phòng gửi lên server phải qua `validateRoom` của `@ctln/shared` trước.

- JS + CSS bản build < 250 KB nén gzip (đặc tả 12).
- Khoá lưu trên trình duyệt: `localStorage` `deviceId`, `myTrees`, `draft:new`, `draft:{treeId}`; `sessionStorage` `ref`. Mọi truy cập bọc try/catch (trình duyệt trong Zalo/Messenger, chế độ riêng tư có thể chặn).
